SEISKA IDELIA SAPUTRI — PINK LEMONADE E-CV

Cara menjalankan:
1. Extract folder Seiska_PinkLemonade_Portfolio.
2. Buka folder tersebut di Visual Studio Code.
3. Jalankan index.html dengan extension Live Server, atau buka index.html langsung di browser.

Halaman:
- index.html: Home
- about.html: About Me
- projects.html: Projects (termasuk link prototype Figma untuk UI/UX Posyandu Melati 6 dan Selbi Salon)
- experience.html: Experience
- certificates.html: Certificates (gambar sertifikat tanpa link eksternal; klik gambar untuk memperbesar)
